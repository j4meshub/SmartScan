# 基础试卷检测与保守净化 POC

本文说明 `POC-004` 的实现范围、安全边界和验收方式。该 POC 用传统视觉验证“不依赖外部 AI 仍能给出试卷建议并安全处理部分彩色笔迹”的可行性，不等于后续 `EXAM-001` 至 `EXAM-003` 的完整产品实现。

## 目标与边界

POC 提供两项独立能力：

- 试卷版式检测：综合长答题线、文字状连通域、选项/答题标记和可选 OCR 关键词命中，输出分数与三级建议。
- 无模板彩色笔迹净化：寻找高饱和度彩色候选，只弱化与印刷内容没有明显冲突的安全区域，同时返回候选、实际处理和复核掩膜。

本阶段不接入生产 Worker，不修改页面或任务数据模型。产品化时必须保存原图、基础结果和处理版本，并允许用户取消净化建议、查看对比和回退原图。

## 试卷建议等级

`detect_exam_layout` 对缩放后的灰度图执行自适应二值化，再提取以下确定性信号：

- 长水平线：答题横线、表格线等版式线索。
- 文字状连通域：页面是否具有密集的小型印刷组件。
- 带孔的小型近方形组件：选择框或答题标记线索。
- `keyword_hits`：为后续自有 OCR 预留的“姓名、班级、考试、试卷、得分”等关键词命中数。

输出等级为：

| 等级 | 行为 |
|---|---|
| `suggest_cleanup` | 高置信，仅建议用户进入净化；用户仍可取消 |
| `ask` | 中置信，询问用户是否为试卷 |
| `ordinary` | 低置信，保持普通扫描 |

规则分数不是训练模型置信度，也不能独立证明真实试卷检出召回率达到 `95%`。真实门禁需要至少 300 页已授权试卷固定集，覆盖模板、无模板、彩色/黑色笔、公式、表格和遮挡，并按来源分组避免相邻页泄漏。

## 保守净化策略

`conservative_color_cleanup` 仅处理 HSV 饱和度和 RGB 色差均明显的彩色组件：

1. 小于 4 像素的孤立色点按噪声忽略。
2. 低饱和度深色区域视为可能的印刷文字、线条或公式并扩张为保护区。
3. 深色彩色候选以及靠近保护区的彩色候选进入复核掩膜，不自动修改。
4. 安全候选只向当前页面的浅色低饱和背景色弱化，不执行生成式补字，也不声称恢复被遮挡原文。
5. 候选面积超过页面 `8%`、复核区域超过候选 `35%`，或没有任何安全候选时，整页返回原图。
6. 黑色笔迹在没有可靠分割模型和印刷保护证据时完全保留。

结果始终包含：

- `candidate_mask`：全部彩色候选。
- `removed_mask`：实际被弱化的安全区域。
- `review_mask`：疑似覆盖印刷内容或过暗的低置信区域。
- `applied`、`needs_review` 和稳定原因码。

三个掩膜在返回后为只读，避免调用方意外改变审计依据。即使局部处理成功，只要存在复核区域就必须在导出前提示用户。

## 自动化证据

合成测试覆盖：

- 高置信试卷版式、空白普通页面和纯关键词中置信路径。
- 孤立彩色笔迹弱化且黑色印刷内容像素保持不变。
- 深色或跨印刷线候选整页回退并要求复核。
- 大面积色块整页回退。
- 灰度页面和黑色手写保持原样。
- 不安全参数拒绝、掩膜只读和二值掩膜契约。

合成测试只证明算法边界可重复，不证明 v1.4 指标已达到。

## 真实验收门禁

产品化前至少完成以下人工与固定数据集验收：

- 试卷检出召回率 `≥95%`，同时报告普通文档误报率和三级建议分布。
- 无模板印刷内容保持率 `≥97%`；任何低置信区域允许回退，回退页不计为成功净化。
- 分别报告彩色笔、黑色笔、公式、表格、遮挡和不同纸张底色。
- 对每个实际修改区域检查原图、处理图和三个掩膜；禁止用视觉上“像原文”的生成内容代替真实文字。
- 记录 CPU、内存、P50/P95 耗时和算法版本；外部 AI 全部关闭时运行。

当前仓库没有满足上述条件的授权固定数据集，因此 POC 代码与合成回归完成后，真实指标仍保持“等待人工验收”。若规则无法达到指标，应在 `EXAM-001`/`EXAM-003` 引入经过固定集验证的轻量分类或分割模型，而不是放宽内容保护和回退条件。
