# 可选视觉 AI 业务接入架构

## 当前事实与目标

`AI-001～AI-005` 已建立 Provider 注册、七类结构化任务、出站安全、可靠性/费用控制和离线评估框架。当前 API、Worker 和三个客户端没有调用该网关，Provider 调用也没有关联用户、项目、页面或页面结果。因此这些工作包只代表 AI 基础设施可用，不代表 SmartScan 已经提供用户可见的 AI 功能。

M8 后续工作把网关接入既有扫描业务，同时保持两条不变约束：外部 AI 关闭或故障时核心扫描、净化、扫书和导出继续可用；任何模型结果都不能直接覆盖基础结果或生成虚假原文。

## 目标调用链

```text
用户按项目授权 AI
  -> 业务 API 校验所有权、授权版本和页面活动版本
  -> 创建 AI 增强任务与可租约处理作业
  -> Worker 签发限时、单页、可撤销的媒体授权
  -> Worker 通过内部认证调用 AI 网关
  -> AI 网关执行 Provider 安全、额度与结构化输出门禁
  -> Worker 再次核对源页面版本并保存候选结果
  -> 用户在客户端对比、接受或放弃
  -> 确定性业务逻辑生成新页面版本或更新已确认元数据
```

页面在 AI 运行期间发生编辑、旋转、重拍或替换时，返回结果只能标记为过期。基础页面始终可预览和导出，AI 失败不把基础任务改为失败。

## 业务接口边界

- `GET /v1/ai/capabilities` 只返回可用能力、是否就绪和传输说明，不返回 Provider URL、Key、内网或 Secret 信息。
- `PUT /v1/projects/{id}/ai-settings` 记录项目级开关、用户、时间和传输说明版本。关闭后撤销未使用媒体授权，并阻止新任务。
- `POST /v1/pages/{id}/ai-enhancements` 以幂等键和当前页面版本创建推荐增强、复杂 OCR、试卷复核或扫书复核任务。
- `GET /v1/pages/{id}/ai-enhancements` 返回当前用户可见的脱敏候选、状态、置信度和模型证据。
- `POST /v1/ai-enhancements/{id}/accept` 只接受仍绑定当前页面版本的候选；过期候选返回冲突。
- 结果预览继续复用 `/v1/pages/{id}/content?version=`，任务取消和重试继续复用现有作业接口。
- `GET /v1/admin/ai/providers` 只读返回脱敏运行状态，不提供在线修改 Key 的能力。

客户端永远不直接访问 AI 网关，也不能提交 Provider ID、URL、Key、媒体完整 URL 或私网允许范围。Provider 由部署配置选择，业务接口只表达 SmartScan 能力。

## 数据与版本

后续迁移采用 expand/migrate/contract：

- 项目保存 AI 是否开启、传输说明版本、授权用户和授权时间。
- AI 增强任务关联所有者、项目、页面、源结果版本、处理作业、任务类型、结构化候选、脱敏模型证据、Provider 调用和稳定错误码。
- 媒体授权只保存高熵令牌摘要、目标页面/任务、有效期和撤销状态；项目、账号或任务删除时立即失效。
- 页面结果保存源版本和脱敏来源证据。只有确定性图像管线实际产生新文件时才增加 `PageResult`，模型文字不能冒充图像版本。
- Provider 调用保留费用与可靠性聚合证据；用户业务关联由增强任务承载，账号或项目删除时清除业务结果和媒体授权。

## 七类任务的业务落点

| 任务 | 业务行为 |
|---|---|
| `classify_page` | 建议普通文档、试卷、书页或封面，不自动改变项目模式 |
| `detect_orientation` | 提示方向；接受后由确定性旋转管线生成版本 |
| `extract_title` | 提供项目/导出名称候选，不覆盖用户名称 |
| `extract_page_number` | 提供扫书页码候选，保留基础页码和冲突证据 |
| `ocr_formula` | 保存公式、表格和复杂版面候选，确认后才能进入 OCR 文本层 |
| `review_cleanup_mask` | 分类候选区域，实际擦除与修补仍由确定性净化管线完成 |
| `review_book_split` | 复核困难书脊和左右页，实际裁切与去弯曲仍由确定性管线完成 |

## Provider 与本机试用

Provider 按 v1.4 继续使用部署级共享配置，Key 只存在于服务端 Secret。本阶段不建设个人 BYOK，也不在 H5、Android 或 iOS 中提供 Key 输入框。公司内网 OpenAI 兼容模型可以作为 `custom_vlm` 使用 Chat 或 Responses 风格适配器，并显式声明精确受控网段。

本机一键试用默认使用明确标注的确定性 Mock，只验证授权、任务、状态、候选和接受流程。真实模式从 `.smartscan-trial/` 下被 Git 忽略的隔离 Secret 读取配置；完成一次配置后仍保持一键启停。Mock 结果不得进入真实固定集、费用、延迟或数据政策验收。

## 客户端与发布顺序

公共 API 和持久化先冻结，再由 H5 完成首条端到端闭环；Android 和 iOS 随后复用同一契约完成能力对齐。H5 优先只是降低当前 Windows 开发环境的反馈成本，不改变三端均为 M8 完成条件。

真实 Provider、授权固定数据集、费用/账单、数据政策和至少一条“项目授权→页面任务→候选结果→用户接受→导出”证据通过前，M8 不得标记完成，生产发布状态保持未就绪。

## AI-006～AI-008 当前实现边界

迁移 `20261022_0023` 已增加项目授权字段、`ai_enhancement_tasks`、页面结果来源版本/证据，以及 Provider 调用到业务任务的可空关联。兼容 API 已提供能力查询、项目开关、页面候选创建/列表和候选接受/放弃。创建请求必须携带当前活动页面版本和幂等键；未授权项目、旧版本、跨用户请求或模式不匹配均失败关闭。

AI 增强任务使用现有 `ProcessingJob` 保存取消、重试和租约边界。基础 Worker 始终显式跳过 `ai_enhancement`；独立 `worker-ai` 只在 `ai` Profile 中启动，领取后使用 `optional_enhancing` 租约状态，并在租约耗尽、失败、取消时同步业务任务和媒体授权。AI-008 只消费 `recommended` 对应的分类、方向、标题和书籍页码任务，公式、试卷与扫书复核仍由 AI-009～AI-011 完成。

页面生成新结果版本时，仍在排队、处理或等待选择的旧源版本候选会标为 `stale`，对应作业会取消；已接受或已放弃的历史决策作为审计证据保留。AI-008 的四类输出先按任务类型形成内部检查点，全部完成前公共 API 不返回半成品；租约重试使用稳定子任务 ID 并跳过已保存结果，最终一次性进入 `candidate_ready`。

迁移 `20261022_0024` 增加 `ai_media_grants`。每次授权使用 `token_urlsafe(32)` 生成至少 256 位随机令牌，数据库只保存 SHA-256 摘要，并绑定唯一增强任务、项目、页面、页面结果及源版本；默认十分钟有效，最长十五分钟。读取时再次检查项目授权、任务状态、活动页面版本、文件路径、大小和哈希，任一不一致统一返回 `404`。项目关闭 AI、页面版本变化、任务失败/取消、项目删除或账号删除都会撤销或删除授权；账号合并同步迁移所有者。

外部 Provider 使用 `/api/v1/ai-media/{token}` 读取媒体。Nginx 仅在该专用只读路径提取令牌、关闭该路径访问日志，并以内网请求头转发到不含令牌的固定 API 路径 `/v1/ai-media`；因此 Uvicorn 访问日志也不会记录令牌。该端点不进入 OpenAPI、无目录浏览且返回 `no-store`，令牌只在 Worker 内存与 Worker→网关请求中短暂存在，不通过业务 API 返回客户端。真实外部 Provider 使用时，部署方必须提供可访问的 HTTPS 地址并把精确前缀写入 Provider 允许列表；AI 网关自身仍无主机端口，也不由公网 Nginx 代理。

AI 网关所有 `/v1/*` 运行接口在配置内部令牌后要求 Bearer 鉴权，生产环境缺失令牌时失败关闭；`/health` 只返回脱敏就绪状态。Worker 客户端固定读取部署级网关地址、Provider ID、媒体前缀与内部令牌，禁重定向且只返回稳定错误码。媒体前缀不会写入候选证据，Worker 只发送其 SHA-256，网关与选中的注册表前缀比较后才允许出站。业务 API 不接受这些参数，H5/Android/iOS 也不会收到它们。能力接口只有在四项部署参数满足安全格式时报告 `available=true`；这表示运行配置完整，不等同于真实 Provider 质量或可达性验收。

四类通用输出在用户接受前不会修改业务对象。接受方向建议时调用现有确定性旋转管线生成新 `PageResult`；接受标题只更新 `suggested_name`，不覆盖用户标题；接受书籍页码写入与旋转后活动版本绑定的页码证据；分类结果保留为接受证据，不自动改变整个项目模式。任何候选非法、版本竞争、网关关闭、超时、5xx 或费用拒绝都只使可选增强失败或重试，基础页面、预览和导出继续可用。

项目或账号删除会清除增强任务、候选内容和媒体授权，并显式断开 Provider 聚合调用记录的业务关联；保留的费用/可靠性聚合不含用户内容。AI-008 不包含公式/复杂版面、试卷、扫书或三端界面，H5 用户闭环由 `H5-AI-001` 承接。
