# H5 页面编辑

## 已实现能力

H5 项目卡片进入页面编辑器后，可以加载当前活动结果并执行：

- 拖动归一化四角，服务端按当前活动结果执行透视裁切；
- 左转、右转，每次操作追加不可变页面结果版本；
- 原图、增强、灰度和黑白四种滤镜，其中浏览器 CSS 仅用于即时预览，最终文件由服务端 Pillow 管线生成；
- 页面前移、后移，服务端要求排序请求精确包含当前项目全部页面，防止并发时静默丢页；
- 展示低分辨率、低对比度及待复核提示，并允许用户确认已复核。

页面内容通过鉴权请求转换为短生命周期 Object URL，不把访问令牌放入图片 URL。关闭编辑器或切换页面会撤销旧 URL。所有编辑从原图或当前活动结果生成新版本，原始文件不会被覆盖；编辑后旧 OCR 标记为过期，等待后续重新识别。

## 服务端边界

四角顺序固定为左上、右上、右下、左下，坐标范围为 `0..1`。服务端拒绝交叉四边形、面积小于原图 2% 或输出边长小于 32 像素的裁切。排序请求有行锁保护，并按所有者隔离；跨用户编辑和排序统一返回 `404` 且记录拒绝审计。

API 契约修订为 `2026-10-20.3`，新增页面编辑与排序操作，旧客户端基线保持不变。

## 删除门禁

计划中的页面永久删除会级联移除原图、处理版本和关联作业，属于不可逆数据破坏。当前未在没有单独明确授权的情况下实现或暴露该操作；H5 不显示伪删除按钮，也不通过仅隐藏数据来冒充删除完成。获得授权后应使用持久化清理记录、可重试文件擦除、页码重排、审计和 IDOR 测试实现，而不是直接散落删除文件。
