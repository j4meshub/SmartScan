# H5 项目恢复、任务与文件分享

## 项目恢复

H5 首页始终从 `/v1/projects` 读取当前用户项目，不把项目内容缓存在浏览器持久存储。打开项目时，地址栏使用 `#project=<id>` 记录当前工作区；页面刷新或认证恢复后，只有该项目仍出现在所有者项目列表中才会自动重开。关闭工作区会清除项目片段。

页面预览继续通过鉴权 Blob 请求获取，访问令牌和刷新令牌不进入下载 URL、分享数据或本地持久文件。

## 任务状态

H5 从 `/v1/jobs` 读取当前用户最近任务，再按当前项目过滤。存在排队、处理、增强或等待重试任务时，每 3 秒刷新任务和导出状态；项目关闭后立即停止轮询。终态任务不会继续产生后台请求。

任务状态仅描述处理生命周期，不代替页面的独立复核状态。自动轮询只证明浏览器状态恢复，真实弱网、后台切换和企业微信内置浏览器仍需人工验收。

## 导出、下载与分享

- 导出复用 `/v1/projects/{project_id}/exports`，支持 PDF/JPG、清晰/均衡/小文件三档质量；OCR 文本层只对 PDF 生效。
- 导出记录和制品文件名来自服务端，H5 不自行拼接存储路径。
- 下载通过 `/v1/export-artifacts/{artifact_id}/content` 鉴权获取 Blob，再以服务端文件名保存。
- 浏览器支持 `navigator.share` 和文件分享时使用 Web Share；用户取消不会触发下载。能力不可用或分享失败时回退为本地下载，并明确提示用户。
- H5 不生成公开链接，不把访问令牌写入 URL，也不把鉴权文件上传到第三方分享服务。

## 自动验证边界

Node.js 测试覆盖项目任务过滤、活动状态轮询判断、双语状态、Web Share 成功和下载回退；静态界面测试固定任务、导出与分享入口。移动端系统分享面板、企业微信文件接收和大文件内存行为保留真机人工门禁。
