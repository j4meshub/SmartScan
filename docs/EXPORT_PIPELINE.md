# JPG/PDF 导出与 OCR 文本层

## 能力边界

`EXPORT-001` 在不依赖外部 AI 的情况下，把页面当前活动结果导出为：

- 单页或多页 JPG：每页生成一个独立制品，不隐式打包为 ZIP；
- 单页或多页 PDF：一个导出请求生成一个 PDF 制品；
- `clear`、`balanced`、`small` 三档质量；
- 可选 OCR 文本层。没有可用 OCR 时仍生成纯图像 PDF。

创建接口为 `POST /v1/projects/{project_id}/exports`，列表和详情接口分别为 `GET /v1/projects/{project_id}/exports` 与 `GET /v1/exports/{export_id}`。本工作包只返回导出元数据；鉴权文件下载、HTTP Range 和 Nginx 内部发送由 `FILE-001` 实现。

## 版本快照与文本真实性

每个导出请求在 `page_snapshot` 中冻结页面 ID、页码、活动结果版本和实际采用的 OCR 版本。只有以下条件全部成立时才写入该页的不可见文本层：

1. `ocr_status` 为 `ready`；
2. `ocr_result_version` 等于当前 `active_result_version`；
3. `ocr_details` 含结构正确的非空行框。

过期、缺失或损坏的 OCR 详情不会从全文字段猜测坐标，也不会生成虚假原文。响应中的 `ocr_pages_used` 是实际写入文本层的页数，可用于客户端提示和验收取证。

## 质量档位

| 档位 | 最长边 | JPEG 质量 | 用途 |
|---|---:|---:|---|
| `clear` | 不主动缩小 | 95 | 归档和打印 |
| `balanced` | 2400 像素 | 85 | 默认查看和分享 |
| `small` | 1600 像素 | 72 | 弱网和小文件 |

所有档位都禁止放大原图。PDF 内嵌的页面图像使用同一档位规则，OCR 坐标按缩放比例映射。

## 文件与数据安全

- 文件写入 `users/{owner_user_id}/exports/{export_id}/`，先写随机 `.incoming` 文件再原子替换；
- `export_artifacts` 保存文件名、MIME、SHA-256、字节数、顺序和可选页面 ID；
- 文件名基于用户项目标题或安全建议名称，过滤路径字符、重复扩展名和 Windows 保留名，并追加扫描日期；
- 普通用户只能创建自己的导出。跨用户创建或读取统一返回 `404` 并记录拒绝审计；管理员只读仍记录成功审计；
- 账号合并会复制、校验并改写导出文件所有者；账号删除显式删除导出记录，并由既有用户目录隔离流程擦除文件。

## 迁移与回滚

迁移 `20261020_0016` 新增 `scan_exports` 和 `export_artifacts`。降级会删除两张导出表和对应元数据，但不会主动删除已经生成的文件；生产回滚前必须先停止新导出，并按导出 ID 清理孤儿目录。数据库降级不等于文件恢复方案。

## 验证

自动测试覆盖多页 JPG、三档缩放中的小文件档、单页/多页 PDF、当前 OCR 文本层、过期 OCR 纯图像回退、稳定文件名、哈希和顺序、IDOR/审计、账号合并、账号删除、迁移升降级与 OpenAPI 契约。PDF 视觉版式、超大项目内存峰值和真实中文文本复制效果仍需在授权样本与目标服务器上验收。
