# Android 可选视觉 AI 接入

## 范围

Android 复用 H5 已验证的公共业务 API，实现项目级授权、通用建议、公式与复杂版面 OCR、任务进度、候选对比、接受或放弃，以及来源基础版本只读预览。AI 仍是可选能力：未开启、未配置、超时或失败时，基础页面预览、编辑和导出保持可用。

本接入不向移动端下发或保存部署方的模型连接配置。应用只读取“能力是否可用、执行模式、传输说明版本、支持的业务类型”以及脱敏后的业务候选；界面、日志和本地缓存均不显示部署标识、连接地址或密钥。

## 分层与数据流

```text
Compose 项目工作区
  -> ProjectRepository 领域接口
  -> AiApi 公共 HTTPS 接口
  -> SmartScan API / AI 专用 Worker / 内部网关
```

- `:core:network` 声明能力、项目设置、候选创建/列表和候选决定 DTO；访问令牌继续由现有请求拦截器放入请求头，不进入 URL。
- `:data:repository` 校验增强类型、源版本和幂等键，把不可信结构化 JSON 收敛成有限的 `AiCandidate` 列表。公式/表格/版面最多读取 40 个块、每个表格最多读取 200 个单元格，单条预览最多 512 个字符。
- `:feature:workspace` 展示固定传输说明，轮询 `queued`/`processing`，并统一解释 `candidate_ready`、`accepted`、`rejected`、`stale`、`failed` 和 `canceled`。
- `:app` 仍只负责依赖装配；AI API 与扫描 API 共用同一个已鉴权客户端，不增加第二套会话或移动端 Secret。

## 用户控制与版本规则

1. 项目未开启 AI 时只显示基础结果可用提示和传输说明，不创建增强任务。
2. 用户点击“同意说明并为此项目开启 AI”后，客户端提交服务端当前公布的说明版本。
3. 创建任务时使用 Android 生成的随机幂等键，并绑定当前 `active_result_version`。
4. 通用建议与复杂 OCR 分开显示；客户端只展示分类、方向、标题、页码、公式、表格、版面文字和置信度。
5. 只有 `candidate_ready` 且来源版本仍是当前版本时，接受/放弃按钮才可用。页面换版后的旧候选可以查看状态，但不能套用。
6. 接受方向候选后如确定性管线生成新图片版本，可只读切换到来源基础版本查看；该预览不改变活动版本和导出选择。
7. 复杂 OCR 接受后只影响版本绑定文字层。Android 明确提示它不修改图片像素，也不伪造所谓“AI 增强图”。

项目已经开启时，即使能力查询或网关临时不可用，关闭按钮仍然可用。关闭后不再允许创建新请求；历史候选按服务端规则保留或失效。

## Mock、真实模式与隐私

能力接口返回 `execution_mode=mock` 时，Android 始终显示“模拟 AI”。该模式只用于验证授权、任务、候选和决定流程，不能作为准确率、延迟、费用或数据政策证据。真实模式仍由部署端统一配置，Android 不提供个人 BYOK 或连接参数输入框。

客户端不会直接访问内部网关，也不会接触媒体授权令牌。页面媒体只由服务端在项目已授权且用户主动请求后签发给内部处理链路；Android 的列表和能力查询不会触发媒体授权或外部调用。

## 自动化与人工验收

仓库门禁覆盖：

- Retrofit 路径、鉴权头、说明版本、幂等键和版本化基础预览；
- 项目授权及能力模型映射，移动端领域对象不包含部署连接配置；
- 分类、方向、标题、页码、公式、表格和版面候选的边界化解析；
- 当前版本选择、运行态轮询、过期候选禁用和 H5 一致的置信度显示；
- Android 单元测试、应用编译、Lint 与无正式签名的 Release 构建。

以下仍是人工或外部门禁：目标 Android 真机的网络切换、进程恢复、TalkBack、长列表性能；真实模型的数据政策、准确率、延迟和费用；正式签名分发。Mock 或模拟器结果不能替代这些门禁。
