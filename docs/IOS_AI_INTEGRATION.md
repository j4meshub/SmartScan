# iOS 可选视觉 AI 接入

## 范围

iOS 复用 H5 与 Android 已验证的公共业务 API，实现项目级授权、通用建议、公式与复杂版面 OCR、任务进度、候选对比、接受或放弃，以及来源基础版本只读预览。AI 仍是可选能力：未开启、未配置、超时或失败时，基础页面预览、编辑和导出保持可用。

本接入不向 iPhone 或 iPad 下发、显示或保存部署方的 Provider、模型、连接地址、内网信息或密钥。应用只读取能力可用性、执行模式、传输说明版本、支持的业务类型和脱敏业务候选；继续复用现有访问令牌、设备会话与刷新机制。

## 分层与数据流

```text
SwiftUI 项目工作区
  -> WorkspaceStore 界面状态与降级边界
  -> WorkspaceRepository 输入校验与令牌刷新
  -> URLSessionSmartScanAPI 公共 HTTPS 接口
  -> SmartScan API / AI 专用 Worker / 内部网关
```

- `WorkspaceAPI` 声明能力、项目设置、候选创建/列表和接受/放弃接口；幂等键只进入请求头，访问令牌沿用已有鉴权请求。
- `WorkspaceRepository` 校验增强类型、源版本、说明版本和幂等键，并在认证过期时只刷新一次。
- `WorkspaceModels` 只解析分类、方向、标题、页码、公式、表格和版面候选。最多读取 40 个复杂块、每个表格 200 个单元格，单条预览最多 512 个字符；响应中的未知部署字段不会进入客户端模型。
- `WorkspaceStore` 将 AI 忙碌和错误状态与基础工作区分开，保留不确定失败时的幂等键，成功后才轮换，并在接受候选后重新读取页面与项目状态。
- `AIWorkspacePanel` 展示固定传输说明、执行模式、两类任务、状态和用户决定；轮询只针对 `queued` 与 `processing`，失败时停止重试风暴。

## 用户控制与版本规则

1. 项目未开启 AI 时，界面只显示本地建议和数据传输说明，不创建增强任务，也不会触发媒体授权。
2. 用户显式同意后，客户端提交服务端当前公布的说明版本；服务端能力不可用时不能开启，但已经开启的项目仍可关闭。
3. 创建任务时使用随机幂等键并绑定当前 `active_result_version`。网络结果不确定时重试仍复用同一键，避免重复候选和重复费用。
4. `recommended` 与 `complex_ocr` 分开显示；客户端只展示有限业务字段和置信度，不解释任意模型 JSON。
5. 只有 `candidate_ready` 且来源版本仍等于当前活动版本时，接受或放弃按钮才可用。旧候选可显示状态，但不能套用到新版本。
6. 接受方向候选导致确定性管线生成新图片版本时，用户可以只读查看来源基础版本或当前版本；预览选择不改变服务端活动版本和导出选择。
7. 复杂 OCR 只生成文字、公式、表格和版面候选；接受后影响版本绑定文字层，不修改图片像素，也不展示虚假的“AI 增强图”。

## Mock、真实模式与隐私

能力接口返回 `execution_mode=mock` 时，iOS 固定显示“模拟 AI”。Mock 只用于验证授权、任务、候选和决定流程，不能作为准确率、延迟、费用或数据政策证据。真实模式仍由部署端统一配置，iOS 不提供个人 BYOK 或连接参数输入框。

iOS 不直接访问内部 AI 网关，也不接触媒体授权令牌。页面媒体只会在项目已授权且用户主动发起页面任务后，由服务端内部处理链路签发和读取；能力查询、候选列表与基础预览不会触发 Provider 调用。

## 自动化与人工验收

仓库自动化覆盖：

- 能力、项目设置、页面任务、幂等键、接受接口和版本化预览路径；
- 授权说明版本、增强类型、源版本和幂等键的仓储校验；
- 七类候选的数量、长度、置信度和方向白名单收敛；
- 当前版本决定、运行态轮询、过期禁用、Mock 标识和来源版本预览；
- 中英文资源、固定 Xcode/XcodeGen 工程生成、iOS Simulator 编译与 XCTest。

以下仍是人工或外部门禁：真实 iPhone/iPad 的 VoiceOver、网络切换、前后台恢复和长列表性能；真实模型的数据政策、准确率、延迟和费用；Apple 签名、Archive、TestFlight 与 App Store。Simulator 或 Mock 结果不能替代这些门禁。
