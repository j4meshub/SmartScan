# Android 编辑、导出、分享与账号删除

## 范围

`AND-005` 把服务端已有的页面版本、复核和导出能力接入 Android 产品界面，并补齐账号删除入口。该工作包不在端侧复制图像算法：旋转、四角校正和滤镜请求由服务端创建新的不可变结果版本，原图仍按服务端规则保留。

## 页面工作区

新增 `:feature:workspace` 模块，提供以下用户链路：

- 恢复当前账号的项目与页面列表；
- 上移或下移页面并提交完整页序；
- 旋转页面，调整归一化四角坐标并选择原图、增强、灰度或黑白滤镜；
- 确认页面已复核；
- 创建 PDF 或多制品 JPG 导出，选择清晰、均衡或小体积质量，PDF 可请求当前 OCR 文本层；
- 下载页面活动结果预览及导出制品。

仓储在发请求前校验页序唯一性、旋转角度、四角范围、滤镜、格式和质量。服务端仍是资源所有权、页面完整集合和结果版本的最终裁决方；未授权与不存在资源保持统一 `404` 行为。

## 下载与系统分享

页面预览与导出制品均通过带 Bearer 会话的 Retrofit 流式接口下载，不向系统下载器或第三方应用暴露访问令牌。文件先写入随机 `.part` 临时文件，导出制品同时校验服务端声明的字节数和 SHA-256；验证成功后才原子替换目标文件，失败时清理临时文件。

系统分享仅开放应用缓存目录 `cache/exports/`：

- `FileProvider` 不导出，并只授予单次读取权限；
- 分享前再次解析 canonical 路径，拒绝子目录逃逸和目录外文件；
- Intent 只携带 `content://` URI 和制品 MIME 类型，不携带令牌、真实路径或用户标识；
- 页面预览目录不在 Provider 白名单内，不能被系统分享。

## 账号删除与撤销

设置页要求完整 E.164 手机号、一次性强验证短信挑战和完全匹配的用户名，才可申请账号删除。服务端接受后进入 7 天冷静期并撤销会话；登录页保留通过手机号和短信验证码撤销删除的入口。

服务端确认申请后，客户端按申请前捕获的用户 ID 执行本地清理：

1. 取消该用户所有已知 WorkManager 唯一上传链；
2. 只删除 `files/captures/originals/` 内、由该用户队列记录的 canonical 文件；
3. 清除该用户的离线上传项目和页面队列；
4. 认证仓储独立清除 Keystore 会话和该用户项目缓存。

清理查询和删除均带用户 ID，不能影响设备中其他用户的队列。路径不在应用私有原图目录时拒绝删除；若任何本地文件或队列清理失败，仍如实显示服务端删除已进入冷静期，同时提示用户在移交设备前通过 Android 系统设置清除应用存储。

## 验证与人工门禁

自动测试覆盖请求路径与请求体、页面映射、页序拒绝、下载大小/SHA-256 校验、失败临时文件清理、账号删除与撤销、本地队列用户隔离、表单校验和界面状态变换。完整 Android 门禁命令见 `AGENTS.md`。

以下项目仍需模拟器或真机人工验收，不能由 JVM/CI 结果替代：

- 大图预览的内存占用、四角滑杆可用性和屏幕旋转恢复；
- Android 目标应用接收 PDF/JPG、多制品逐项分享及 URI 权限回收；
- 下载中断、后台切换、账号删除与正在运行 Worker 并发；
- 7 天冷静期内使用真实短信撤销后重新登录；
- TalkBack、动态字体、中英文长文本和至少一台目标 Android 真机完整流程。
