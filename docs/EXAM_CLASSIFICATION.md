# 试卷页面分类、建议与取消

本文说明 `EXAM-001` 的分类输入、版本边界、客户端行为和真实数据集门禁。分类只决定是否向用户建议试卷净化，不直接修改页面，也不替代 `EXAM-002`/`EXAM-003` 的内容保护与回退规则。

## 分类链路

Worker 在文档透视和 OCR 完成后运行本地 CPU 分类。外部 AI 关闭、未配置或故障时，规则分类仍可独立完成。

规则信号包括题号、分值、选项、答题横线、装订线、公式密度、中英文试卷关键词和页面版式。OCR 文本只在进程内用于统计；数据库只保存命中数量、各信号分数、总概率和算法版本，不复制识别出的原文。

可选轻量模型必须实现本地 `LightweightExamClassifier` 协议并返回 `0` 到 `1` 的概率及明确模型版本。融合权重固定为规则 `55%`、模型 `45%`。模型异常、越界或返回非有限数时立即回退规则，不把内部错误或输入文本写入结果。

显式选择“试卷净化”模式属于用户意图，结果使用 `user-selected-exam-v1`，概率为 `1.0`。扫书模式关闭试卷分类；普通文档模式运行规则或融合分类。

## 置信区间与产品行为

| 区间 | 当前阈值 | 客户端行为 |
|---|---:|---|
| 高置信 | `probability >= 0.65` | 显示“建议使用试卷净化”，同时说明原图保留 |
| 中置信 | `0.25 <= probability < 0.65` | 询问用户是否切换到试卷净化 |
| 低置信 | `probability < 0.25` | 保持普通文档，不显示建议 |

`predicted_exam` 的判定阈值为 `0.50`。产品提示使用独立 `recommendation`，避免把“分类概率”误当成已经执行净化。

H5、Android 和 iOS 都把新增字段作为可选增量字段读取，旧服务端缺少字段时按普通页面显示。用户点击“暂不使用”只取消当前处理结果版本的建议；不会清除机器证据，也不会影响其他页面或新生成的结果版本。

## 数据与版本边界

页面保存以下分类状态：

- 分类状态、分类器版本、结果版本、预测值、概率、置信区间、建议和结构化信号证据；
- 取消建议对应的结果版本、操作用户、时间和稳定原因码；
- 分类更新时间。

分类证据必须满足 `exam_result_version == active_result_version` 才能驱动界面。旋转、裁切或滤镜生成新结果后，旧分类立即失效并等待重新处理。取消接口为：

```http
PUT /v1/pages/{page_id}/exam-suggestion-dismissal
Content-Type: application/json

{"result_version": 3, "reason": "user_dismissed"}
```

接口只允许页面所有者操作。管理员和其他用户与资源不存在统一返回 `404` 并记录拒绝审计；过期结果版本返回 `409`，避免迟到请求取消新版本建议。重复取消同一版本保持幂等。

迁移 `20261021_0018` 采用 expand/backfill：既有页面标记为 `legacy`，不会伪造历史分类结果；回滚只移除新增分类列和约束，不删除页面或处理结果。

## 自动化证据

自动测试覆盖规则与轻量模型融合、模型故障回退、显式试卷模式、关键词证据不泄露原文、Worker 版本关联、扫书关闭、编辑失效、取消幂等、迟到版本冲突和普通用户/管理员 IDOR 审计。

三端测试覆盖增量字段解析、建议显示和取消请求的正式路径与 JSON 负载。OpenAPI 当前快照新增可选响应字段和新端点，上一代客户端基线不变。

## 固定数据集人工门禁

分类代码完成不等于指标通过。进入 `EXAM-002`/`EXAM-003` 的算法放量前，需要准备不少于 300 页的授权、脱敏固定数据集，至少包含：

- 中英文试卷、选择题、填空题、公式、表格、装订线及不同纸张底色；
- 普通讲义、合同、书页、表格、票据等相似负样本；
- 拍照旋转、阴影、模糊、低对比度和局部遮挡样本。

报告必须按算法版本给出召回率、普通文档误报率、高/中/低置信分布、混淆矩阵、CPU/内存以及 P50/P95 耗时。试卷召回率目标为 `>=95%`；误报率必须如实报告并经产品验收，不能通过放宽高置信阈值或隐藏负样本达到召回目标。

当前仓库没有合格固定数据集，因此 `EXAM-001` 在自动化实现完成后保持“等待人工验收”。若规则或轻量模型未达标，应调整阈值、模型或产品范围，不得把低置信页面自动净化。
