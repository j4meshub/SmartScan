# 双页拆分与保守去弯曲 POC

本文说明 `POC-005` 的传统视觉实现、安全回退和真实验收边界。该 POC 验证在外部 AI 关闭时，可以根据书页外轮廓和书脊暗谷拆分展开书籍，并只在几何分数改善时采用边界去弯曲结果。

## 实现范围

`split_book_spread` 执行以下步骤：

1. 用 Otsu 二值化和形态学操作提取亮色书页面积，估计整本展开书的外接范围。
2. 在书宽的中间 `20%–80%` 搜索纵向亮度暗谷，避免假定书脊位于图片中心。
3. 用左右页面参考亮度计算书脊对比度，并分别计算左右区域的书页覆盖率。
4. 书脊与两侧均可信时独立裁切左右页，保留不等宽页面。
5. 严格使用项目传入的 `left_to_right` 或 `right_to_left` 排列逻辑页，不从界面语言推断。
6. 书脊不可信、外轮廓缺失或一侧覆盖不足时只返回一张未修改原图，不把桌面当成第二页。

本阶段不接入生产 Worker、页面数据模型或单侧重拍流程。后续 `BOOK-001` 至 `BOOK-003` 负责自动快门状态机、每侧质量和替换关系、页码/重复/缺页以及增量成册。

## 保守边界去弯曲

`conservative_dewarp_page` 从亮色页面掩膜提取逐列顶部和底部边界，分别拟合一次直线和二次曲线：

- 有效边界覆盖率低于 `70%` 时返回原页。
- 二次曲率低于页面高度的 `0.5%` 时认为无需校正。
- 二次曲率超过页面高度的 `12%` 时视为高风险并返回原页。
- 在可信范围内，用确定性纵向网格消除相对线性边界的二次偏移。
- 重新计算输出边界几何分数；默认至少改善 `0.02` 才采用，否则返回原页。

这一 POC 只验证页面边界几何，不把边界变直等同于文字已经正确去弯曲。产品化需要加入文字行水平度、字符宽度稳定性和 OCR 置信度，任一关键指标变差都应回退透视或原页版本。

## 结构化结果

拆分结果包含：

- `pages`：一个单页回退，或按明确阅读顺序排列的左右逻辑页。
- 每个逻辑页的 `side`、图像和独立 `DewarpResult`。
- 原图坐标系中的 `spine_x`、书本边界、拆分置信度和稳定原因码。
- 去弯曲的采用状态、输入/输出几何分数和回退原因。

独立结果使后续产品能够只重拍或替换失败的一侧，而不覆盖另一侧已经确认的页面。

## 自动化证据

合成测试覆盖：

- 明显偏离图片中心的书脊和左右不等宽页面。
- 左到右与右到左两种显式阅读顺序。
- 单页没有可信书脊时保留一张完整原图。
- 缺少第二页时不拆分桌面背景。
- 可信二次边界曲率且输出分数改善时采用去弯曲。
- 直页不做无意义变换，过度曲率返回原页。
- 非法阅读顺序、书脊阈值、覆盖率和去弯曲阈值被拒绝。

合成测试不能覆盖厚书阴影、手指、反光、浅色桌面、复杂插图或真实文字基线，不作为真实指标通过证据。

## 真实验收门禁

按照 v1.4，固定数据集至少应包含 `5` 本书、`1000` 个逻辑页和 `300` 次双页捕获，并覆盖书脊不居中、左右宽度不同、厚书、手指和快速翻页。验收至少包括：

- 双页正确拆分率 `≥95%`。
- 双页顺序正确率 `≥99%`。
- 单页和缺侧场景不得虚构第二页。
- 左右页分别检查边界、文字完整性、曲率、方向和可重拍状态。
- 去弯曲同时比较边界直线度、文字行水平度和字符宽度，结果变差时必须回退。
- 记录 CPU、内存和 P50/P95 耗时；外部 AI 全部关闭时运行。

当前仓库没有授权真实书籍固定集，因此代码和合成回归完成后，`POC-005` 的真实拆分率、顺序和去弯曲质量仍保持“等待人工验收”。若传统视觉未达到指标，应先调整产品范围或在固定集上验证轻量书脊分割模型，不能通过降低单页回退标准获得表面通过率。
