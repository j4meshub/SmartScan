# 可选视觉 AI 固定评估集

本目录只保存清单和安全示例，不提交真实扫描图片、原始模型输出、媒体 URL、令牌或个人数据。真实图片放入被 Git 忽略的 `images/`，实际运行结果放入被 Git 忽略的 `runs/`。

## 数据要求

- 每份数据必须有授权、脱敏、许可、同意依据和用途记录。
- 按 `source_group` 划分 `train`、`validation`、`test`；同一文档、试卷或书籍不得跨切分，避免相邻页泄漏。
- 每个样本记录图片 SHA-256、任务完整输入和人工复核的期望结果。任务媒体摘要及尺寸必须与文件一致。
- v1.4 的总体验收规模仍是普通文档不少于 300 页、试卷不少于 300 页、书籍不少于 5 本且包含不少于 1000 个逻辑页和 300 次双页取景；中英文、公式、表格、弯曲、阴影、试卷笔迹和书名均需覆盖。
- 准确率、幻觉率、结构化成功率、P95 延迟和平均成本阈值必须由负责人评审并写入清单，不能用示例阈值冒充产品结论。

`manifest.example.json` 和 `run.example.json` 中的全零摘要只是格式占位，因此不能直接执行，也不能作为门禁证据。完整流程见[可选视觉 AI 固定评估](../../docs/AI_FIXED_EVALUATION.md)。
