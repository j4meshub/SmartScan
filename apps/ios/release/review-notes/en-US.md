# App Review Notes

SmartScan is a document scanning app. All core scanning, editing, and export features work without optional external AI.

Use the non-administrator review account entered in App Store Connect. Credentials and any SMS bypass code are stored only in the secure App Review fields; they are never committed to this repository. The account must remain active and must open the complete product flow immediately.

Suggested review path: sign in, open a seeded project, preview and edit a page, create a PDF export, share it, then open Manage Account to locate the in-app account-deletion flow. If SMS is required, follow the current code procedure supplied in App Store Connect review notes.

The review backend must remain available throughout review. Camera capture requires a physical device; the seeded project allows the rest of the flow to be reviewed without creating private content.
