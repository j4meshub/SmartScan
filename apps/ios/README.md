# iOS app

Open this folder in Xcode 16+, create an iOS App target named `SmartScan`, and add the Swift source files. The first committed screen establishes the SwiftUI design and localization-ready strings. Camera capture (AVFoundation), Vision OCR, Core Image correction, Keychain tokens, BackgroundTasks uploads, account deletion and App Store signing require an Apple team, a frozen Bundle ID and physical-device verification.
