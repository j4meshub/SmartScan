# iOS 应用

使用 Xcode 16 或更高版本打开此目录，创建名为 `SmartScan` 的 iOS App Target，并加入现有 Swift 源文件。当前提交的首页用于建立 SwiftUI 视觉基线和可本地化字符串结构。

以下内容仍需 Apple 开发者团队、冻结后的 Bundle ID 和真实设备验证：

- 基于 AVFoundation 的相机拍摄。
- Vision OCR 与 Core Image 图像校正。
- Keychain 令牌保存和 BackgroundTasks 断点上传。
- 完整账号删除流程。
- App Store 签名、TestFlight 和公开审核。
